# UX Flow Guide (IdeaGen)

This guide explains how a non-technical user moves through the app to generate ideas, compare runs, and create decision-ready reports.

## Key Terms
- **Constraints**: "must-have conditions" for the idea — the rules the output has to follow (budget, compliance, team size, timeline, offline needs).
- **Persona**: the writing style or point of view (e.g., Operator focuses on workflow/ROI; Founder focuses on market/vision).

---

## Flow 1: Generate Ideas
1. **Pick a Target Industry** in the Configuration panel.
2. **Select Constraints** (rules the idea must follow).
3. **Choose an AI Persona** (tone of the output).
4. **Pick AI Models** you want to use.
5. Click **Generate Ideas**.
6. Results appear in tabs by model. The run is **auto-saved**.

What you get:
- A multi-model output in the Results area.
- An automatic **model ranking** (if more than one model was used).

---

## Flow 2: Review Model Ranking (Per Run)
1. After generation, look for the **Model Ranking** block above the model tabs.
2. It summarizes the strongest output and provides ranked rationale.
3. If only one model was used, it will say ranking is not available.

---

## Flow 3: Manage Saved Results
1. Open **Saved Results**.
2. Choose a view:
   - **Generated Results**: load a prior run.
   - **Compare Results**: compare two runs with the same configuration.
   - **Decision Summary Report**: rank multiple runs and summarize.
3. Use **Load** to restore a run to the Results area.
4. Use **Delete** to remove saved runs.

---

## Flow 4: Compare Results (Diff Insight)
Use this only when both runs used the same Industry, Persona, Constraints, and Models.

1. Open **Saved Results** → **Compare Results**.
2. Click **Show** under “Select two runs”.
3. Pick **Run A** and **Run B**.
4. Click **Compare**.
5. View the **Diff Insight** panel with:
   - Winner
   - Key changes
   - Risks
   - Top outputs compared

What you get:
- A comparison saved for later reuse.
- Export options for PDF/email.

---

## Flow 5: Decision Summary Report (Across Runs)
Use this when you want a ranked summary across multiple saved runs.

1. Open **Saved Results** → **Decision Summary Report**.
2. Click **Show** under “Select runs for the report”.
3. Choose **1–5 runs**.
4. Click **Decision Summary Report**.
5. Review the report:
   - Ranked runs with scores
   - Key insights
   - Risks (5+ bullets)
   - Next steps

What you get:
- A decision-ready summary across runs.
- Export options for PDF/email.

---

## Flow 6: Export or Email Reports
1. Use the **Export** card in the Results view.
2. Choose **PDF**, **Email**, or **Both**.
3. For email, enter a recipient address.
4. Click **Download** or **Send**.

Report types available:
- Generated Results
- Compare Results (Diff Insight)
- Decision Summary Report

---

## Flow 7: Usage & Limits
1. Check **Current Usage** at the top.
2. Hover a label to see the current usage vs plan limit and refresh cadence.
3. Use the refresh icon to update usage on demand.

---

## Common Tips
- If Compare Results fails, make sure both runs used the exact same configuration.
- If ranking is missing, the run likely used only one model.
- Use Decision Summary Report to choose the best run across multiple saved results.
