# Reports: Compare and Rank (Simple Guide)

This page explains two features in plain language: Compare Report and Rank Report.

## Compare Report (Diff Mode)
What it does:
- You pick two saved runs (A and B).
- The system reads both and explains the differences.
- It tells you which run looks stronger and why.
- It saves the comparison so you can open it later.

When to use it:
- You have two options and want a clear side‑by‑side decision.
- You want a short explanation of why one is better.

What you get:
- Winner: A, B, or tie.
- Short summary of the main differences.
- Key changes between the two runs.
- Reason why the winner was picked.
- Risks or tradeoffs.

How to use it:
1) Open “Load Results.”
2) Click “Compare” on two runs (A and B).
3) Click “Compare” to generate the report.
4) The result appears in the main Results panel.

## Rank Report (Agentic Rank Report)
What it does:
- You pick 1 to 5 saved runs (or all saved runs).
- The system ranks them from strongest to weakest.
- It explains the ranking and gives next steps.
- It creates a PDF you can download or email.
- It saves the report so you can download it later.

When to use it:
- You have several options and want a full ranking.
- You need a decision‑ready report to share.

What you get:
- Overall summary of the landscape.
- Ranked list with a score and short reason for each run.
- Key insights across all runs.
- Risks and recommended next steps.
- Optional diff memo (if you selected exactly two runs and already ran Compare).

About the diff memo:
- It only appears when you select exactly two runs and have already run Compare on those same runs.
- It adds the Compare Report summary (decision, key changes, and risks) inside the Rank Report PDF.
- If you have not run Compare yet, the Rank Report will say the diff memo is missing.

How to use it:
1) Open “Load Results.”
2) Click “Include” on 1‑5 runs (or select all).
3) Click “Rank Report.”
4) Choose PDF, Email, or both.
5) Generate the report.
6) Find past reports under “Saved rank reports” and download anytime.

## Notes on saving
- Compare Reports are saved automatically.
- Rank Reports are saved automatically.
- Rank Report downloads can use a saved snapshot, so they still work even if a run was deleted later.
